## 🧪 التجربة

### 0. جهّز مساحة عمل Linear شخصية (مرة وحدة — 3 دقائق)

> ⚠️ **نفس قاعدة Sentry:** مساحة عمل **شخصية جديدة مجانية** — مش workspace الشركة! سجل على linear.app بإيميلك الشخصي وأنشئ workspace جديدة (سمّها مثلاً `omar-lab`) — بيجي معها team افتراضي جاهز.

### 1. وصّل Linear MCP

```bash
claude mcp add -s user --transport http linear https://mcp.linear.app/mcp
```

بعدين جلسة `claude` → `/mcp` → **linear** → **Authenticate** → وافق **بحسابك الشخصي** (انتبه بشاشة التفويض تكون على الـ workspace التجريبية).

### 2. المشهد الرئيسي — تذكرة حقيقية بالعامية

افتح جلسة بالـ playground:


واحكيله متل ما بتحكي لزميل:

**شو لازم يصير:** الـ skill بتنشط لحالها (من الوصف) → بتصيغ التذكرة إنجليزي عالقالب → أول مرة بس: بتسألك أي team → **بتنشئ التذكرة فعلياً** → بترجعلك المعرف والرابط (متل `OMA-1`). افتح Linear بالمتصفح — التذكرة قاعدة هناك 🎫

### 3. اختبار السياسات — الاثنتين

1. **problem-only لسا حية:** اطلب: *"ضيف عالتذكرة إنه الحل يكون بحفظ الفلاتر بالـ state"* → لازم يرفض بأدب (نفس موديول 00 — السياسة انتقلت مع الترقية)
2. **تذكرة ثانية أسرع:** جرب وحدة كمان بالعامية — لاحظ إنه ما رجع سألك عن الـ team (حفظها من أول مرة)
