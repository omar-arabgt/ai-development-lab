## ليش هاد الموديول بعد Sentry؟

Sentry علّمنا الدورة: إشارة خارجية → تحقيق → إصلاح → PR. بس مصدر الشغل الثاني (والأكبر) هو **البشر**: ملاحظات، مشاكل، طلبات — وهاي بتعيش بـ Linear. هالموديول بيبني نفس الأنابيب لمصدر البشر.
