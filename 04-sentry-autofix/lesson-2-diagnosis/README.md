# الدرس 2: المحقق — من التقرير للجاني

## 🗣️ بالعامية

بدرس 1 الـ AI صار يقرأ تقرير الحادث (الـ issue بـ Sentry). بس التقرير لحاله ما بيصلّح شي — المحقق الشاطر بياخد التقرير وبيروح **لمسرح الجريمة** (الكود) ويربط: "الرصاصة اللي بالتقرير طلعت من هالمسدس بالسطر 29".

هاد الدرس هو هالربطة بالضبط: **جلسة وحدة** بتسحب الـ issue من Sentry (عبر MCP)، بتدور بالكود المحلي (بأدواتها العادية)، بتشخّص السبب الجذري، وبتصلّح — وبتثبت إصلاحها بإعادة تشغيل السكربت. عيون بالسحابة + إيدين على جهازك، بنفس الجلسة.

ولاحظ إنا منفصل **التشخيص عن الإصلاح** ببرومبتين — نفس فلسفة "الأسئلة قبل التخمين": التشخيص بيطلع قدامك أول، انت بتوافق، بعدين التنفيذ.

## 🔧 بالتقني

شو بيصير تحت الغطا لما تطلب التشخيص:

```
1. mcp__sentry__ (أداة MCP)   → بيسحب الـ issue: النوع، الرسالة، الـ stack trace
2. Stack trace بيقول: import_listings.dart:29
3. Read/Grep (أدوات محلية)    → بيفتح الملف، بيقرأ حوالين السطر
4. الربط: الفيد بيبعت "12,500 JOD" ← double.parse بيتوقع رقم خام
5. التشخيص + اقتراح الإصلاح   → قدامك للقرار
```

هاي أول مرة أدوات MCP (سحابة) وأدوات محلية (ملفات) بيشتغلوا **سوا بنفس المهمة** — وهاد اللي بيميز الـ agent عن الـ chatbot: مش بس بيعرف، بيوصل المعلومة من مصدرها لمكان استخدامها.
