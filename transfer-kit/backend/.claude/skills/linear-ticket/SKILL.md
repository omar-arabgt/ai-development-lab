# Linear Ticket Creator (ArabGT edition)

Turn a rough description (any language) into a formatted ticket AND create it in Linear.

## Procedure

1. Read the description carefully.
2. If environment (dev/qa/staging/production) or platform (iOS/Android) is unclear, ask ONE short question.
3. Fill the structure in `template.md` — exact section order.
4. Ticket content in English, regardless of input language.
5. Title format: `[Area] Short problem statement`.
6. Destination is FIXED: team **ArabGT**, project **"ArabGT Mobile App"** — the company's single shared Linear project (mobile + backend). Do not ask, do not use any other project.
7. Create the issue; reply with identifier, URL, and a reminder to attach the screenshot in Linear.

## Team policy (strict)

- **Problem only. NEVER propose solutions, fixes, or root causes.** If asked, politely decline: tickets describe problems; solutions are discussed by the team.
- One ticket per issue; multiple problems = multiple tickets.
- Steps to reproduce: numbered, starting from app launch.
