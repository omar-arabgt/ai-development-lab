# الدرس 1: أول insights — الـ AI بيقرأ سلوك المستخدمين

## 🗣️ بالعامية

Sentry بيخبرك لما التطبيق **ينكسر**. بس مين بيخبرك لما التطبيق شغال تمام و**المستخدمين مش مبسوطين**؟ صفحة ولا حدا بيفتحها، بحث ولا حدا بيكمل بعده، زر حجز محطوط بمكان ولا حدا بيوصله؟

هاد شغل **PostHog** — عداد الحركة تبع التطبيق: كل كبسة وبحث ومشاهدة بتنسجل كـ **event**، والأسئلة الكبيرة ("شو أكثر موديل بينشاف؟ الآيفون ولا الأندرويد أنشط؟ البحث بيوصل لحجز؟") بتنجاوب من تجميع ملايين الأحداث الصغيرة. هاد اللي انذكر بالميتنغ — وهاد الدرس بيفهمك شو هو، وليش مهم، وكيف الـ AI بيحكي معه.

والزبدة تبعت الموديول: التقارير اللي بياخدها المدير من "حدا بيفتح الداشبورد ويطلع سكرينشوتات" — بتصير سؤال بالعامية والـ AI بيجاوبه من البيانات الحية.

## 🔧 بالتقني — وانتبه على المفتاحين

| مفتاح | شكله | وظيفته | سريته |
|---|---|---|---|
| **Project API Key** | `phc_...` | **إرسال** الأحداث من التطبيق | عادي يظهر بالكود العام (بيقدر يكتب بس، ما بيقرأ) |
| **Personal API Key** | `phx_...` | **قراءة** البيانات والتحكم (وهاد اللي بياخده الـ MCP) | **سر حقيقي** — متل الباسوورد |

نفس فلسفة الصلاحيات تبعتنا: مفتاح الكتابة العمومي مفصول عن مفتاح القراءة السري — تسريب الأول مزعج، تسريب الثاني كارثة.

## 🎯 الـ playground

`bin/seed_events.dart` — بيزرع **أسبوع كامل من حركة مستخدمين واقعية** لسوق السيارات: مشاهدات موديلات، عمليات بحث، طلبات حجز — 8 مستخدمين، منصتين، وأنماط مقصودة مخبية بالبيانات (مش عشوائي بحت 😉) عشان يكون للـ AI شي **يكتشفه** فعلاً.

## 🧪 التجربة

### 0. حساب PostHog (مرة وحدة — 5 دقائق)

> ⚠️ العادة المقدسة: حساب **شخصي مجاني** (us.posthog.com — الخطة المجانية أكثر من كافية)، مش أي حساب شركة.

1. سجل وأنشئ مشروع جديد (نوعه: Product analytics)
2. من Settings → Project → انسخ الـ **Project API Key** (`phc_...`)
3. من Settings → Personal API Keys → أنشئ مفتاح جديد (صلاحيات قراءة كافية) وانسخه (`phx_...`)

### 1. ازرع أسبوع الحركة

```bash
cd /Users/omarabed/Documents/work/sandbox/ai-development-lab/07-analytics-posthog/lesson-1-first-insights/playground
export POSTHOG_PROJECT_KEY="phc_مفتاحك"
dart run bin/seed_events.dart
```

(لازم: "Seeded ~100 events across the last 7 days" — وافتح PostHog → Activity وشوفهم عم يوصلوا)

### 2. وصّل الـ MCP

```bash
claude mcp add -s user --transport http posthog https://mcp.posthog.com/mcp --header "Authorization: Bearer phx_مفتاحك_الشخصي"
```

(لاحظ: المفتاح **الشخصي** هون — القراءة — مش تبع المشروع)

### 3. حاور بياناتك

افتح جلسة `claude` واسأل بالراحة:

> From my PostHog data for the last 7 days: what are the top events? Which car model gets the most views? What's the iOS vs Android split? And is there any pattern in activity across the days of the week? Summarize like a product analyst.

**شو تتوقع:** يجاوب من البيانات الحية — وفي 3 أنماط مزروعة قصداً بالبيانات، شوف كم واحد بيمسك (وقارن مع الكود بعدين 😄).

### سؤال التثبيت

Sentry وPostHog الاثنين "عيون على الإنتاج" — شو الفرق الجوهري بين نوع الأسئلة اللي بيجاوبها كل واحد؟ *(تلميح: واحد بيحكيلك عن اللحظات اللي التطبيق خذل المستخدم، والثاني عن اللحظات اللي المستخدم استخدم — أو تجاهل — التطبيق)*
