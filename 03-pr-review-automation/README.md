> 🔨 شغالين عليه

كل PR بينفتح → فحوصات ومراجعة تلقائية عالسحابة. أول موديول بيشتغل **بدون ما حدا يشغله** — الحدث (فتح PR) هو المشغّل.

## ليش هاد الموديول بعد Spec-Driven؟

موديول 02 أعطانا الحكم المحايد — بس كان بيركض على جهازك ولما **انت** تتذكر. هون منحطه عالبوابة: بيركض **لكل PR، لكل واحد بالفريق، دايماً**. وبعدها منضيف فوقه مراجعة AI كاملة.
