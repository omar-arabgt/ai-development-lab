# موديول 02: Spec-Driven Development

> ✅ خلص + الديمو مجرّب + موثّق

من مواصفات مكتوبة صح → كود كامل بيحترم العقد حرفياً. الجملة الذهبية: **جودة الكود اللي بيطلع = جودة العقد اللي دخل**.

## ليش هاد الموديول بعد Parallel Agents؟

بموديول 01 تعلمنا نشغّل كذا agent بالتوازي — بس شو بنعطي كل agent؟ لو أعطيناهم طلبات ضبابية، بنستلم تخمينات بالتوازي 😅. الـ spec هو اللي بيخلي التفويض آمن: عقد واضح لكل عامل، وحكم محايد بيفحص التسليم.
