## سلايد 2 — Multi-Agent Development
**⏱ دقيقتين**

**اللي عالسلايد:** الفكرة + رقم كبير: 5 tasks → the time of the longest one + جدول القواعد الثلاثة.

**شو بتحكي:**
"خلينا نبلش من الفكرة الأم. اليوم لما منستخدم AI، واحد منا بيفتح شات وبيطلب شغلة وبيستنى. المنهجية الجديدة: **كذا agent يشتغلوا بنفس الوقت على نفس الريبو**. السر اللي بيخلي هاد ممكن بدون كوارث هو ثلاث قواعد:
- كل agent بياخد **نسخة معزولة** من الريبو (git worktree) — ولا واحد بيلمس ملفات الثاني
- التقسيم **بالملفات**: مهمتين ما بيلمسوا نفس الملف = صفر تعارض بالتصميم، مش بالحظ
- **مايسترو واحد** بيوزع وبيستنى وبيدمج — انت بتحكي المهام مرة وحدة

النتيجة: خمس مهام بتخلص بوقت أطول وحدة فيهم، مش بمجموعهم. وهاي ميكانيكا git صافية — بتشتغل مع جلسات Claude ومع background agents تبعت Cursor."

**سؤال متوقع هون:** "وإذا مهمتين بدهم نفس الملف؟" → "المايسترو بيرفض يوازيهم وبيشغلهم بالتسلسل — القاعدة محفورة بالإجراء نفسه، مش متروكة لذاكرة حدا."

## سلايد 3 — Before Any Agent Runs: The Setup
**⏱ دقيقتين ونص — هاد سلايد الثقة، خذ وقتك**

**اللي عالسلايد:** جدول: ذاكرة المشروع / الصلاحيات وملفات التعديل / حراس production — بعمودين Claude وCursor.

**شو بتحكي:**
"قبل ما أي agent يكتب سطر، في تجهيز بينركب **مرة وحدة وبيعيش جوا الريبو نفسه** — يعني أي حدا يعمل clone، القوانين بتيجي معه:

1. **ذاكرة المشروع** — ملف بيعرّف الـ AI على المشروع من أول ثانية: البنية، الأعراف، الممنوعات. عنا بـ Claude اسمه CLAUDE.md، وبـ Cursor: ملفات .cursor/rules. بدونه كل جلسة بتبلش من الصفر وبتخترع أعراف من عندها.

2. **الصلاحيات وملفات التعديل** — قوائم صريحة: شو مسموح ينفذ بدون سؤال، شو لازم إذن، شو ممنوع نهائياً — وأي ملفات إله حق يعدلها. مش أدب واتفاق — النظام بيفرضها.

3. **حراس الـ production** — وهون النقطة الأهم: كود بيفحص كل عملية **قبل تنفيذها**، وأي شي بيلمح لقاعدة بيانات إنتاج أو مساحة عمل الشركة الحقيقية بينمنع فوراً برسالة واضحة. هاي بـ Claude اسمها hooks — وهي من الفروقات الجوهرية: Cursor ما عنده مقابل كامل لها.

الخلاصة: الأمان مش وعد من الموظف ولا من الـ AI — **محفور بالبنية**."

## سلايد 4 — How Agents Work On Your Machine
**⏱ دقيقتين**

**اللي عالسلايد:** 5 خطوات مرقمة: نسخة معزولة → توازي → commits → دمج → PR واحد.

**شو بتحكي:**
"طيب عملياً، وين هالشغل بيصير؟ **كله محلي على جهاز المطور** — وهاي نقطة بتريح كثير ناس:

كل مهمة بتاخد نسخة معزولة على نفس الجهاز — مجلدك الرئيسي والمحرر المفتوح ما بينلمسوا. الـ agents بيشتغلوا بالنسخ، كل واحد بيعمل commit لشغله، المايسترو بيدمج وبيمسح النسخ، وبيطلع **PR واحد** — هاد الشي الوحيد اللي بيغادر الجهاز.

وإذا agent خرب شي؟ كل شي ملجون بـ git — الرجوع بثواني. وقبل أي عملية جريئة في عادة اسمها checkpoint: سطر واحد بيعمل نقطة حفظ متل الألعاب."

## سلايد 5 — Signals & Skills: Sentry, Linear, Procedures
**⏱ دقيقتين ونص**

**اللي عالسلايد:** جدول: Sentry / Linear / Skills وشو بيعمل الـ AI مع كل واحد.

**شو بتحكي:**
"لحد هون حكينا عن كود بينكتب. بس مصادر الشغل الحقيقية ثلاثة، وكلها موصولة بالـ AI عبر موصل موحد اسمه MCP — بيحكيه Claude وCursor الاثنين:

- **Sentry**: لما crash يوصل من مستخدم، الـ AI بيقرأ التقرير والـ stack trace، بيفتح الكود، بيوصل للسطر المذنب، بيجهز الإصلاح كـ PR، وبيسكر البلاغ. الدورة اللي بتاخد نص يوم triage بتصير دقايق.

- **Linear**: من الاتجاهين — موظف بيوصف مشكلة **بالعامية** والـ AI بيحولها تذكرة منسقة بمعايير الفريق وبينشئها فعلياً؛ والتذاكر الجديدة بتنفرز لحالها: أولوية، تصنيف، وربط المكررات — حتى لو وحدة بالعربي ووحدة بالإنجليزي. وأبعد من هيك: التذكرة بتتحول لأسئلة → مواصفات → تنفيذ، والتذكرة بتحدث حالها.

- **Skills**: إجراءات الفريق مكتوبة مرة وحدة — كيف منكتب تذكرة، كيف منوزع مهام متوازية — والسياسات مخبوزة جواها: تذكرة بلا حلول مقترحة؟ الـ skill نفسها بترفض تكتب حل. ما حدا بحاجة يتذكر السياسة — السياسة بتفرض حالها.

الجملة المفتاحية: **معرفة الفريق بتنتقل من روس الناس لملفات ملجونة — وكل agent بيطيعها.**"

## سلايد 6 — Testing: Three Stages
**⏱ دقيقتين ونص — سلايد الـ QA، جمهورك بيهتم فيه**

**اللي عالسلايد:** جدول المراحل الثلاثة: Integration tests / GitHub Actions / Firebase Test Lab.

**شو بتحكي:**
"الفحص عنا بثلاث مراحل، مرتبة بالكلفة — والمبدأ الاقتصادي: **الـ AI بيكتب الفحص مرة وحدة** من وصف بالعامية — وهاد الجزء الغالي اللي الفرق بتأجله سنين — **وأدوات مجانية حتمية بتشغله للأبد**:

1. **Integration tests**: رحلة المستخدم مكتوبة ككود — يفتح، يتصفح، يحجز، يتأكد من التأكيد. بتركض على simulator وبتفشل بوضوح عند أي كسر.

2. **GitHub Actions**: المشغّل والبواب — على كل PR بتركض فحوصات العقود ومراجعة الـ AI والدمج مقفول لحد ما تخضرّ؛ وكل ليلة الرحلات كاملة على **iOS وAndroid** مع تقرير نجح/فشل لكل منصة. بدون ما حدا يتذكر يشغل شي.

3. **Firebase Test Lab**: أسبوعياً، نفس الفحوصات بتنبعت لأجهزة **فيزيائية حقيقية** — Pixel وSamsung بغرف سيرفرات Google — وبيرجع تقرير وفيديو تشغيل لكل جهاز. لأنه emulator ما بيمسك غرائب أجهزة السوق الحقيقية.

وكل هاد **بدون أي منصة QA خارجية مدفوعة**: إطار الفحص جاي مع Flutter، المشغل هو GitHub اللي كودنا عليه أصلاً، ومعرض الأجهزة إله حصة مجانية يومية."

## سلايد 9 — Who Runs the Automation: The AWS Server
**⏱ دقيقتين**

**اللي عالسلايد:** جدول التوزيعة: أجهزة المطورين / GitHub Actions / سيرفر AWS.

**شو بتحكي:**
"آخر قطعة بالصورة: مين بيشغل كل هاد؟ التوزيعة على ثلاث طبقات:

- **أجهزة المطورين**: الشغل التفاعلي اليومي والـ agents المحلية — وكل شي بيظل محلي لحد الـ PR
- **GitHub Actions**: البوابات والفحوصات المجدولة — سيرفرات بتتأجر عند الحاجة، مربوطة بالريبو، وتقاريرها موثقة على كل تشغيلة
- **سيرفر AWS صغير دايم الصحو**: هاد بيت الأتمتة الحقيقية — بيستقبل الـ webhooks (crash من Sentry، تذكرة من Linear)، بيشغل الجدولة (التقرير الصباحي 7:00، الفرز كل ساعة)، بيدير الأنابيب بلا واجهة، وبيوصل النتائج على Slack. ليش سيرفر؟ لأنه اللابتوبات بتنام — وهاد ما بينام.

ونقطة التكلفة: **instance صغير بيكفي تماماً** — الشغل الثقيل بيصير عند مزود الـ AI عبر API، السيرفر بس بيسمع وبيجدول وبيوزع. مش مشروع بنية تحتية — صندوق صغير بوظيفة سكرتير دوام ليلي."

## ملحق: أجوبة الجيب (لو انسألت)

- **"قديش بيكلف؟"** → مراجعة PR كاملة بالـ API ≈ $0.40. التشغيل الكامل شهرياً أقل من كلفة يوم عمل مهندس. الأرقام موثقة بوثيقة التكاليف من المصادر الرسمية.
- **"شو بيمنع تسريب كود الشركة؟"** → نفس ضمانات أي أداة سحابية منستخدمها (GitHub نفسه سحابة) — والحسابات بخطط عمل ما بتتدرب على بياناتنا.
- **"ليش مش منصة QA جاهزة؟"** → لأنها بتبيع شغلتين: كتابة فحوصات بدون كود (الـ AI بيعملها عنا ببلاش) وتشغيلها (GitHub بيعملها ببلاش). بنضل محتاجين بس معرض أجهزة — وإله حصة مجانية.
- **"إيمتى منبلش؟"** → المرحلة الأولى (الذاكرة + الصلاحيات + بوابات الـ PR) بتنركب على ريبو واحد بيوم شغل، وبنقيس على أول أسبوعين.
