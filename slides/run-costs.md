**رقم واقعي من المختبر (مش تقدير):** مراجعة الـ PR الكاملة اللي مسكت المشكلتين المزروعتين (21 دورة تفكير، Sonnet) كلفت **$0.396** — يعني حتى بـ 100 PR بالشهر: **~$40/شهر** لمراجعة AI على كل PR.

## 2. تكلفة بنية الفحص (QA)

### GitHub Actions

| البند | السعر |
|---|---|
| ريبو **عام** | **مجاني بالكامل** — بلا حدود (هيك المختبر شغال بصفر تكلفة) |
| ريبو خاص — دقايق مشمولة | 2,000 دقيقة/شهر (خطة Free) أو 3,000 (خطة Team) |
| ريبو خاص — Linux إضافي | $0.006/دقيقة |
| ريبو خاص — macOS إضافي | $0.062/دقيقة (~10x — عشان هيك iOS ليلي والباقي على Linux) |

**تقدير لريبو الشركة الخاص** (الجدول الليلي تبعنا: ~15 دق macOS + ~20 دق Linux):
≈ $1.05/ليلة ≈ **~$32/شهر** — وأول 2,000-3,000 دقيقة Linux مشمولة أصلاً فالفعلي أقل.

## 3. الفاتورة الشهرية المتوقعة لـ ArabGT — ثلاث مراحل

| المرحلة | شو شغال | التقدير الشهري |
|---|---|---|
| **اليوم (المختبر)** | كل شي — على ريبو عام واشتراك Pro واحد | **$20** (الاشتراك الموجود أصلاً) |
| **Phase A-B** (بوابات PR + صبحية على ريبو الشركة) | مراجعة AI لكل PR (~100/شهر ≈ $40) + تقرير يومي (~$10) + دقايق CI (~$30) | **~$80-100** + اشتراكات المطورين الحالية |
| **التشغيل الكامل** (كل الأنابيب والجداول) | فوق السابق: أنابيب التذاكر والأخطاء + فحوصات موسعة | **~$150-250** تقديرياً — والفوترة بالـ API شفافة لكل أنبوب فبتشوف بالضبط وين كل دولار |

**نقطة البيع للإدارة:** التكلفة الكاملة أقل من ساعات عمل يوم واحد لمهندس — مقابل: مراجعة على كل PR، فحوصات ليلية على منصتين، أجهزة حقيقية أسبوعياً، وتقارير صباحية — كلها بدون توظيف ولا منصة QA خارجية (اللي اشتراكاتها لحالها بتبدأ من مئات الدولارات شهرياً).
