# خطة ديمو ArabGT الحقيقي — Mobile + Backend

> الهدف: ديمو حي **على كود ومنظومة ArabGT الفعلية** بيمشي بنفس تسلسل التعلم: الذاكرة ← Skills ← الحدود والأمان ← MCP ← الختام الكبير: **multi-agents بيسحبوا Sentry bugs الحقيقية وبيرفعوها بطاقات على Linear**.
> مقسومة: **تجهيز** (قبل الديمو، مع Claude) و**العرض الحي** (10-12 دقيقة).

---

## قرارات السلامة أولاً (قبل أي خطوة)

الحراس الحاليين بيمنعوا **أي** لمسة لمساحات arabgt — للديمو منستبدلهم بحراس **مفصلين بدقة**:

| الخدمة | المسموح بالديمو | الممنوع (بيظل محروس) |
|---|---|---|
| Sentry (org الشركة) | **قراءة فقط**: عرض/بحث/تفاصيل issues | أي كتابة: resolve، assign، تعديل — ممنوعة بالحارس |
| Linear (workspace الشركة) | **إنشاء وتعليق فقط جوا مشروع/فريق مخصص اسمه "Sentry Bugs"** | أي كتابة بأي team/project ثاني — ممنوعة بالحارس |
| قواعد البيانات والبيئات | ولا شي جديد | كل أنماط prod + `manage.py migrate/shell` — زي ما هي |
| كود الشركة | تعديلات **على branches فقط** → PRs للمراجعة | ولا push مباشر لأي فرع محمي |

> **مبدأ الديمو**: نوسّع بالضبط قد الحاجة — قراءة Sentry (بلا خطر) وكتابة بصندوق رمل واحد معزول جوا Linear ("Sentry Bugs") بيشوفه الفريق بس ما بيلخبط شغلهم.

## التجهيز — قبل الديمو (جلسة شغل مع Claude، ~ساعتين)

### الخطوة 0: الحراس الجدد + صندوق الرمل
- تعديل حارسي Sentry/Linear بـ `~/.claude/settings.json` للنسخة المفصلة أعلاه
- إنشاء المشروع/الفريق **"Sentry Bugs"** بـ Linear الشركة (من الواجهة — دقيقة)
- **إطلاق نار تجريبي**: نجرب كتابة بـ Sentry الشركة (لازم تنصد) وكتابة بفريق ثاني بـ Linear (لازم تنصد) وإنشاء بـ "Sentry Bugs" (لازم يمشي)

### الخطوة 1: الذاكرة — CLAUDE.md + .cursor/rules (للريبوهين)
- clone ريبو الموبايل وريبو الـ Django محلياً + branch باسم `ai-foundations` بكل واحد
- **Claude يدرس كل ريبو ويكتب مسودة CLAUDE.md**: البنية، الأعراف، الممنوعات — نبذة المشروع اللي حكيت عنها
- عمر يراجع ويعدل (انت أدرى بالأعراف غير المكتوبة!) ← مرآة بـ `.cursor/rules`
- **لقطة إثبات للديمو**: جلسة جديدة + سؤال "شو بيعمل هالمشروع وكيف أضيف feature؟" — بيجاوب من الذاكرة صح

### الخطوة 2: الـ Skills
- نسخ + تكييف من المختبر لـ `.claude/skills/` بريبو الموبايل:
  - `linear-ticket` (بسياسة problem-only) — موجهة لفريق الشركة الصح
  - `parallel-tasks` (بسياسة "ولا agent-ين على ملف")
  - **الجديدة للديمو**: `sentry-sweep` — الإجراء الكامل للختام (تحت)

### الخطوة 3: الحدود والأمان بالريبو
- `.claude/settings.json` بكل ريبو: permissions (allow: analyze/test/pytest؛ deny: نشر/أسرار) + حراس production بأسماء ArabGT **الفعلية** (خصوصاً Django: manage.py على أي بيئة غير محلية)
- **لقطة إثبات للديمو**: أمر بريء الشكل فيه اسم prod DB — بينصد قدامهم برسالة الخط الأحمر

### الخطوة 4: MCP
- ملف `.mcp.json` بجذر كل ريبو (sentry + linear) — توثيق "كل مطور بيصادق بحسابه"
- فحص: قراءة أول 3 issues من Sentry الشركة بالحوار

### الخطوة 5: بناء skill الـ sentry-sweep (نجم الديمو)
الإجراء المكتوب بـ `.claude/skills/sentry-sweep/SKILL.md`:
1. اسحب الـ **top N unresolved issues** من Sentry الشركة (مرتبة بعدد المستخدمين المتأثرين — N افتراضي 6 عشان الديمو يظل نظيف)
2. وزّعهم على **agents متوازيين** (batch لكل agent — هون لقطة الـ multi-agent)
3. كل agent، لكل issue: يقرأ التفاصيل والـ stack trace → يكتب بطاقة Linear بمشروع **"Sentry Bugs"**: عنوان `[Area] المشكلة`، الوصف، عدد المستخدمين والتكرارات، رابط الـ Sentry issue، أول ظهور، وseverity مقترحة
4. **فحص التكرار قبل الإنشاء**: إذا في بطاقة موجودة لنفس الـ issue — يعلق عليها بدل ما يكرر
5. تقرير ختامي: كم بطاقة انعملت، كم مكرر انربط، ورابط البورد
- **بروفة كاملة مرتين** + سكرينشوتات طوارئ لكل لقطة

## العرض الحي — التسلسل (10-12 دقيقة)

| # | اللقطة | شو بيشوفوا | الرسالة |
|---|---|---|---|
| 1 | **الذاكرة** (2 دق) | جلسة جديدة بريبو الموبايل: "اشرحلي هالمشروع وكيف أضيف feature" — بيجاوب بدقة من CLAUDE.md | "الـ AI صار يعرف مشروعنا من أول ثانية — والمعرفة بالريبو، للكل" |
| 2 | **Skill** (دقيقة) | `/linear-ticket` بوصف مشكلة بالعامية → بطاقة منسقة | "إجراءات الفريق مكتوبة مرة — والسياسة بتفرض حالها" |
| 3 | **الحارس** (دقيقة) 🔥 | أمر فيه اسم prod DB → **صد فوري** برسالة الخط الأحمر | "الأمان محفور بالنظام — حتى أنا ما بقدر أغلط" |
| 4 | **الختام الكبير** (4-5 دق) 🌟 | أمر واحد: `/sentry-sweep` → agents متوازيين يشتغلوا → **بورد "Sentry Bugs" بـ Linear بيتعبى قدامهم بطاقة بطاقة** ببيانات أخطائهم الحقيقية | "هاد مش سيناريو — هاي أخطاؤنا الفعلية، اتفرزت واترفعت بدقايق. هيك بيشتغل المصنع" |
| 5 | **الخاتمة** (دقيقة) | البورد الجاهز + "كل بطاقة فيها الرابط والأثر وعدد المستخدمين" | "والخطوة الجاية بالخطة: البطاقة تتحول PR — بموافقتكم" |

**خطة الطوارئ**: سكرينشوت/تسجيل شاشة لكل لقطة من البروفة — لو النت خرب، العرض بيكمل بالصور بلا توقف.

## شو منحتاج منك قبل ما نبلش التجهيز

1. **روابط/أسماء الريبوهين** (الموبايل والباك إند) وصلاحية clone
2. **أسماء بيئات/قواعد الإنتاج الفعلية** — غذاء الحراس (ولا منشاركها بأي مكان عام — بس بالحراس المحليين)
3. **موافقتك على تعديل الحارسين** للنسخة المفصلة (قراءة Sentry + كتابة بـ Sentry Bugs بس)
4. قرار: الديمو هاد **جوا عرض الثلاثاء** ولا بعده كمرحلة أولى من النقل؟
