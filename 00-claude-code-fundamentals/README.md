# أساسيات Claude Code

> 🔨 شغالين عليه

هاد الموديول هو **الأساس لكل شي بعده**. كل درس فيه: شرح بالعامية + شرح تقني + تجربة عملية بتعملها بإيدك.

## الدروس

| # | الدرس | الفكرة بجملة | الحالة |
|---|-------|--------------|--------|
| 1 | [CLAUDE.md — ذاكرة المشروع](lesson-1-claude-md/) | ملف بيخلي الـ AI يفهم مشروعك وقوانين فريقك من أول ثانية | ✅ مثبت بالتجربة |
| 2 | [Permissions — الصلاحيات](lesson-2-permissions/) | شو مسموح للـ AI يعمل بدون إذنك وشو لأ | ✅ مثبت بالتجربة |
| 3 | [Hooks — الحرّاس](lesson-3-hooks/) | كود بينفذ أوتوماتيك عند أحداث معينة، وبيقدر يمنع الـ AI | ✅ مثبت بالتجربة |
| 4 | [Subagents — الموظفين المتخصصين](lesson-4-subagents/) | agents بتعرّفهم انت، كل واحد بتخصصه وصلاحياته | 🔨 |
| 5 | Skills — المهارات | تعليمات جاهزة بتنشحن للـ AI لما يحتاجها | ⏳ |

## ليش هاد الترتيب؟

```
CLAUDE.md      ← الـ AI بيفهم مشروعك        (المعرفة)
Permissions    ← بتحدد شو مسموحله           (الحدود)
Hooks          ← بتفرض قوانين ما بتنكسر     (الحماية)
Subagents      ← بتوظف متخصصين              (الفريق)
Skills         ← بتعطيهم إجراءات جاهزة      (الخبرة)
```

كل درس بيبني على اللي قبله. بالآخر بتكون فاهم كل القطع اللي منركّب منها أي أتمتة بالموديولات الجاية.
