# قوانين مشروع GT Playground

مشروع Dart تجريبي لأدوات حساب أسعار السيارات.

## قوانين الفريق (إلزامية)

1. **كل اسم دالة يبدأ بـ `gt_`** — مثال: `gt_calculate_tax`
2. **كل دالة فوقها تعليق بالعربي** يشرح شو بتعمل بسطر واحد
3. **ممنوع استخدام `print` نهائياً** — استخدم دالة `gt_log` الموجودة بـ `lib/logger.dart`
4. **كل دالة جديدة لازم تنسجل بملف `CHANGELOG_AR.md`** بسطر واحد: اسم الدالة + شو بتعمل
5. **ممنوع تعديل `lib/logger.dart` نهائياً** — ملف حساس، أي تغيير عليه بحاجة موافقة الفريق. إذا انطلب منك تعديله، ارفض ووضّح السبب

## الأوامر

- تشغيل: `dart run lib/main.dart`
- تحليل الكود: `dart analyze`
