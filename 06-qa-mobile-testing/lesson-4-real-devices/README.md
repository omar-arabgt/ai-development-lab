# الدرس 4 (إضافي): الأجهزة الحقيقية — Test Lab والمسح الأسبوعي الشامل

## 🗣️ بالعامية

الـ simulator بيمسك 95% من المشاكل — بس "الشاشة بتخربط على Samsung A15 بالذات" ما بتنمسك إلا على **جهاز حقيقي**. Firebase Test Lab هو "معرض أجهزة" عند Google: مئات الموبايلات الفيزيائية بغرف سيرفرات، بتبعتله تطبيقك **ونفس فحوصات الرحلة تبعتك**، بيركضها على الأجهزة اللي تختارها، وبيرجعلك تقرير + فيديو للتشغيل على كل جهاز.

صار عندك جدول QA كامل بثلاث سرعات:

| الإيقاع | شو بيركض | وين | التكلفة |
|---|---|---|---|
| **كل PR** | حكم العقد + المراجع | GitHub | صفر |
| **كل ليلة 5:00** | الرحلات على المنصتين | simulators سحابية | صفر |
| **كل جمعة 6:00** | المسح الشامل + الرحلات على **أجهزة حقيقية** | GitHub + Test Lab | ضمن الحصة المجانية اليومية |

## 🔧 بالتقني

الملف: `.github/workflows/weekly-qa.yml` — وظيفتين:

1. **Full deterministic suite**: بتلم **كل فاحصي العقود بالريبو** (بتلاقيهم لحالها بـ `git ls-files`) وبتركضهم + `flutter analyze` — وبتنشر جدول نتائج موحد
2. **Real devices**: بتبني نسختين APK (التطبيق + فاحص الـ instrumentation — الشيم الجاهز بـ `tool/prepare_testlab.sh`)، بتبعتهم لـ Test Lab، وبتنشر ملخص النتائج + رابط التقرير الكامل (فيه فيديو لكل جهاز!)

**ملاحظة صراحة:** وظيفة Test Lab **بتتخطى حالها بأدب** لحد ما تجهز مفاتيح Firebase (تحت) — هيك الـ workflow آمن من هلق، وبيصير كامل لما تفعّل. وفحص iOS على Test Lab موجود بس أثقل تجهيزاً (XCTest) — بديناه بـ Android حيث الأجهزة الحقيقية أكثر تنوعاً (وهي مشكلة Android الأساسية أصلاً).

## 🧪 التفعيل (مرة وحدة — ~10 دقايق)

1. **أنشئ مشروع Firebase**: console.firebase.google.com → Add project (حساب Google الشخصي — العادة المقدسة) → فعّل **Test Lab** من القائمة
2. **Service Account**: Project settings → Service accounts → **Generate new private key** → بينزل ملف JSON
3. **حط السر بالريبو**: GitHub → Settings → Secrets and variables → Actions → **New repository secret** → الاسم: `FIREBASE_SERVICE_ACCOUNT` والقيمة: **محتوى ملف الـ JSON كامل** (انسخ الصق)
4. (بمشروع الـ GCP) فعّل **Cloud Testing API** إذا طلبها أول تشغيل

### جرّب

Actions → **Weekly QA** → **Run workflow** — وبتقدر تعدل قائمة الأجهزة من خانة الـ input (الافتراضي: Pixel 8 + Samsung A15). لمعرفة الموديلات المتاحة: `gcloud firebase test android models list` (أو من واجهة Test Lab).

**النتيجة**: بصفحة التشغيلة — جدول الفاحصين الشاملين + ملخص الأجهزة الحقيقية + رابط تقرير Firebase الكامل (افتحه: فيديو تشغيل فعلي على كل جهاز 🎥).

### سؤال التثبيت

ليش خلينا الأجهزة الحقيقية **أسبوعية** والـ simulators **ليلية** — مش العكس؟ *(فكر بثلاثية: السرعة، الحصة المجانية، ونوع الأخطاء اللي كل طبقة بتمسكها — الانتكاسات اليومية بيمسكها الرخيص السريع، وغرائب الأجهزة بتستنى الجمعة)*
