# الدرس 3 (إضافي): QA عالسيرفر — الفحص بيصير موظف دوام ليلي

## 🗣️ بالعامية

بدرس 2 كتبت فحص الرحلة وشغلته **بجهازك بإيدك**. سؤالك الطبيعي كان: "بدي شي يعمل QA لحاله عالسيرفر" — وهاد بالضبط هالدرس: نفس فحص الرحلة تبعك، بس هلق **بيسكن على سيرفر GitHub** وبيشتغل بحالتين:

1. **كل ليلة الساعة 5:00 الصبح** (بتوقيت عمّان) — موظف الدوام الليلي
2. **بكبسة زر من المتصفح** — للديمو والطلب

السيرفر (ماكينة macOS حقيقية بالسحابة، ببلاش للريبو العام) بيبني تطبيقك، بيقلّع iPhone simulator، بيمشي رحلة الحجز كاملة، **وبيصوّر الشاشة الأخيرة كدليل** بتقدر تنزّله. لابتوبك مسكّر؟ نايم؟ عالبحر؟ — الفحص شغال.

## 🔧 بالتقني

الملف: `.github/workflows/nightly-qa.yml` — اقرأه، كله مفاهيم بتعرفها:

- `on: schedule: cron: '0 2 * * *'` — **درس المنبّه (م09 د2)** بس بالسحابة بدل لابتوبك (الحل لمشكلة "اللابتوب بينام")
- `on: workflow_dispatch` — زر تشغيل يدوي بواجهة GitHub (للديمو)
- `runs-on: macos-latest` — GitHub بيأجرنا ماك حقيقي (الوحيد اللي بيشغل iOS simulators) — **مجاناً للريبوهات العامة**
- `flutter create . --platforms=ios` جوا الـ workflow — لأنه مجلد ios/ مش ملجون (قرارنا من درس 1) — السيرفر بيولّده طازة كل مرة
- خطوة الدليل: سكرين شوت بـ `if: always()` (حتى لو الفحص فشل — **خصوصاً** لو فشل) بينرفع كـ artifact

## 🧪 التجربة

### 1. شوفه بيشتغل هلق (مش الساعة 5 الصبح 😄)

افتح الريبو على GitHub → تبويب **Actions** → بالقائمة الجانبية **Nightly QA** → زر **Run workflow** → Run.

### 2. اتفرج عالموظف الليلي يشتغل مباشرة

اكبس عالتشغيلة → job اسمها **User journeys on iOS simulator** → شوف الخطوات تتنفذ: تنصيب Flutter → توليد iOS → إقلاع الـ simulator → **الرحلة** (هاي بتاخد كم دقيقة — بناء iOS كامل عالسحابة).

### 3. نزّل الدليل

بعد ما تخلص (✓)، بصفحة التشغيلة تحت — قسم **Artifacts** → نزّل **qa-evidence** → جواه سكرين شوت آخر شاشة من الرحلة، مصورة من simulator عايش على سيرفر ما لمسته بحياتك 📸

### 4. والليلة؟

ولا شي عليك — هاي النقطة. بكرا الصبح افتح Actions ولاقي تشغيلة جديدة صارت الساعة 5:00 لحالها. (وهي رح تضل تشتغل كل ليلة — هاد موظف بدوام مش تجربة، وتكلفته عالريبو العام: صفر)

### سؤال التثبيت

الفحص الليلي فشل الساعة 5 الصبح وانت نايم — شو أول تحسين منضيفه عالـ workflow ليصير الفشل **حدث بيوقظ أنبوب** بدل سطر أحمر بينتظر حدا يفتح Actions؟ *(تلميح: عندك الجواب من موديول 09 — الفشل نفسه بيصير trigger: إشعار، أو حتى `claude -p` بيشخّص ويفتح تذكرة Linear لحاله... كل القطع عندك 😉)*
