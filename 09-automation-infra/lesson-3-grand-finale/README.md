# الدرس 3: الختام — المصنع كامل والبروفة الأخيرة 🏁

## 🗣️ بالعامية

ما في مفهوم جديد اليوم — **خلصت المفاهيم** 😄. الدرس الأخير إله شغلتين: (1) تطلع فوق وتشوف **المصنع كامل** بصورة وحدة — كل قطعة بنيتها وين قاعدة بالخط، و(2) **بروفة الديمو** — لأنه أحلى مصنع بالعالم ما بيسوى إذا العرض تلعثم.

اقرأ [JOURNEY.md](../../JOURNEY.md) بجذر الريبو — وثيقة الرحلة الكاملة: الخريطة، المبادئ العشرة، سجل الحوادث. **هاي مش توثيق وبس — هاي مادة عرضك ومصدر NotebookLM.**

## 🧪 التجربة الأخيرة: بروفة الديمو الحي

العرض الأقوى مش سلايدات — **مشهد حي**. السيناريو المقترح (45 ثانية لكل لقطة):

### اللقطة 1 — "هاد المختبر" (دقيقة)
افتح صفحة الريبو على GitHub: جدول الموديولات العشرة بعلامات ✅ — "كل علامة وراها ديمو اشتغل بإيدي". افتح GLOSSARY.md ثانيتين — "وهاد قاموس المصطلحات اللي تعلمناها، عربي إنجليزي".

### اللقطة 2 — البوابات الحية (3 دقايق) ⭐ الديمو الرئيسي
حضّر **قبل** العرض branch جاهز فيه الفانكشن المفخخة (مفتاح مزروع + قسمة على صفر — نفس sneaky-green). قدامهم: افتح PR → البوابات بتشتغل live → الحكم أخضر (العقد سليم!) بس مراجع الـ AI بيعلق عالمشكلتين مع اقتراح إصلاح → "أخضر ≠ سليم، وهاد الفرق بين الحارسين".

### اللقطة 3 — الجرس (دقيقتين)
التيرمينال: شغّل مستمع الـ webhook، ابعت curl "وصل crash من Sentry" → الأنبوب بيصحى ويكتب تشخيص كامل قدامهم — "هيك بيشتغل المصنع الساعة 3 الفجر".

### اللقطة 4 — الصبحية (دقيقة)
افتح تقرير صباحي جاهز (بالعربي!) — "هاد بيكتب حاله كل يوم عالمنبّه — Sentry وPostHog بتقرير واحد مع توصية".

### الختام (30 ثانية)
JOURNEY.md → قسم "المرحلة الثانية": الخطة المرحلية للنقل لريبو الشركة، والخط الأحمر الثابت.

### قواعد البروفة

1. **مرتين كاملتين** بالتوقيت — المرة الأولى بتكتشف العثرات، الثانية بتثبت
2. **خطة الطوارئ**: سكرينشوت لكل لقطة محفوظ بمجلد — لو خرب النت/التيرمينال، بتكمل بالصور بدون توقف
3. **جهّز الأجوبة** لأسئلتهم المتوقعة: "قديش بيكلف؟" (اشتراك واحد + API للفريق لاحقاً)، "شو عن أمان كودنا؟" (موديول 08 كامل جوابها)، "Cursor ولا هاد؟" (مش منافسة — resources/cursor-claude-code-mapping.md)
