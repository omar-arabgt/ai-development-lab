# الدرس 2: المنبّه — الوقت نفسه بيصير زناد

## 🗣️ بالعامية

درس 1 كان الزناد **حدث** ("صار crash!"). بس في شغلات ما إلها حدث — إلها **موعد**: التقرير الصباحي كل يوم 7:00، بروفة الاسترجاع أول كل شهر، الفحص البصري كل أحد. هون الزناد هو **الساعة** — وأداتها العتيقة المبجلة اسمها **cron**: جدول مواعيد بيعيش بنظام التشغيل، وبينفذ اللي عليه بوقته، صحيت انت ولا نمت.

اليوم مناخد "الصبحية" تبعت موديول 07 — اللي شغلتها بإيدك وقتها — **ومنحطها على المنبّه**. آخر إصبع إلك بيطلع من الصورة 😄

## 🔧 بالتقني

### صيغة الموعد — 5 خانات

```
دقيقة  ساعة  يوم-الشهر  الشهر  يوم-الأسبوع
 0      7      *          *      *          ← كل يوم 7:00 الصبح
*/2     *      *          *      *          ← كل دقيقتين (للتجربة)
 0      4      *          *      0          ← كل أحد 4:00 (فحص أسبوعي)
```

### قاعدة الـ wrapper — أهم درس عملي بالجدولة

cron بيشغّل أوامرك ببيئة **عارية**: بلا PATH تبعك، بلا مجلدك الحالي، بلا أي شي من جلستك. أول ما حدا بيجرب cron بيصطدم بـ "الأمر شغال بإيدي وفاشل بالجدولة!" — والسبب دايماً البيئة. الحل النمطي: **سطر الجدولة بيظل تافه، وكل الذكاء بسكربت wrapper** ملجون بالريبو (شوف `scripts/morning_report.sh`): بيصرّح الـ PATH، بيحدد المجلد، بيسجل بداية ونهاية. (نفس عبرة "الفحص المعلق عالسؤال التفاعلي" — بالأتمتة كل شي صريح)

## 🧪 التجربة

### 1. جرب الـ wrapper بإيدك أول (قاعدة: ما بنجدول شي ما اشتغل يدوي)

```bash
/Users/omarabed/Documents/work/sandbox/ai-development-lab/09-automation-infra/lesson-2-scheduling/playground/scripts/morning_report.sh
```

(بياخد دقيقة — وبيطلع تقرير جديد بمجلد reports تبع موديول 07، هالمرة باسم فيه الساعة)

### 2. جدوله كل دقيقتين (مؤقتاً — للمشاهدة)

```bash
(crontab -l 2>/dev/null; echo "*/2 * * * * /Users/omarabed/Documents/work/sandbox/ai-development-lab/09-automation-infra/lesson-2-scheduling/playground/scripts/morning_report.sh >> /tmp/lab-cron.log 2>&1") | crontab -
crontab -l
```

> 💡 macOS ممكن يطلب إذن مرة: "Terminal would like to administer your computer" أو إشعار عن cron — اسمحله.

### 3. سكّر التيرمينال واستنى ٤ دقايق ⏳

بجد — روح اعمل قهوة. هاي النقطة كلها: **ما في إيدك بالموضوع.** بعدين ارجع وشوف الدليل:

```bash
cat /tmp/lab-cron.log
ls /Users/omarabed/Documents/work/sandbox/ai-development-lab/07-analytics-posthog/lesson-2-morning-report/reports/
```

تقارير جديدة بأسماء أوقات مختلفة = المصنع اشتغل مرتين وانت عالقهوة ☕

### 4. **فك الجدولة فوراً** (وإلا بيضل يكتبلك تقارير كل دقيقتين للأبد 😅)

```bash
crontab -l | grep -v morning_report | crontab -
crontab -l
```

### 5. النسخة الحقيقية — وين بتعيش فعلاً؟

لابتوبك بينام، بيسكر، بيسافر معك — **الجدولة الحقيقية بتعيش على سيرفر دايم الصحو**. وعندك واحد ببلاش أصلاً: GitHub Actions بيدعم الجدولة بنفس الصيغة:

```yaml
on:
  schedule:
    - cron: '0 4 * * *'   # 4:00 UTC = 7:00 صباح عمّان
```

نفس الـ workflows اللي بتعرفها من موديول 03 — بس المشغّل صار الساعة بدل الـ PR. (منركبها فعلياً بجلسة النقل — بدها secrets للمفاتيح عالريبو، قرار لوقته)

### سؤال التثبيت

عندك هلق **3 أنواع زناد**: حدث خارجي (webhook)، موعد (cron)، وفعل إنسان (PR/أمر). وزّع أنابيب المختبر السبعة عالزنادات الصح: مراجعة الكود؟ الصبحية؟ إصلاح الـ crash؟ الفحص البصري؟ triage التذاكر؟ بروفة الاسترجاع؟ الرحلات؟ *(ما في جواب واحد صح — بس في أجوبة غلط: صبحية بـ webhook مثلاً 😄)*
